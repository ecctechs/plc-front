## วันที่ 1 — ข้อความแจ้งเตือนหน้า Interaction / ผู้ใช้
- [x] (18/11/69) **หน้า INTERACTION (เพิ่ม Element)** — เปลี่ยน "HTTP error! status: xxx" ตอนบันทึก Element ไม่สำเร็จ เป็นข้อความที่อ่านเข้าใจ (`AddElementModal.vue:321`)
- [x] (18/11/69) **หน้า SETTING (ผู้ใช้ / บทบาท)** — หัวข้อแจ้งเตือนเป็น "Error" ภาษาอังกฤษตลอด และข้อความสำรอง "Update failed / Reset failed / Save failed / Delete failed / Cannot load roles" ยังไม่แปลไทย (`UserSettingModal.vue`, `RoleSettingModal.vue`, `ProfileModal.vue`)

## วันที่ 2 — ข้อความจาก Backend ที่ผู้ใช้เห็น
- [ ] **BACKEND (ข้อความ)** — ข้อความ error ที่ส่งกลับไปให้หน้าเว็บยังปนอังกฤษ/ศัพท์โค้ด เช่น `name is required`, `Room not found`, `Email already in use`, `employee_id already exists`, `address_id and display_type are required` → เปลี่ยนเป็นภาษาไทยที่อ่านเข้าใจ ให้เข้ากับข้อความไทยที่มีอยู่แล้ว
- [ ] **หน้า LOGIN** — ตรวจข้อความ "Invalid credentials" / "Your account is not assigned to a company" ให้เป็นภาษาไทยเมื่อเลือกภาษาไทย

## วันที่ 3 — Alarm ไม่ถูกบันทึก (บั๊กสำคัญ)
- [ ] **BACKEND (ALARM)** — แก้ Alarm ระดับ error/critical ไม่ถูกบันทึกและไม่ส่งอีเมล เพราะส่งค่าให้ฟังก์ชันบันทึก Downtime ผิดตำแหน่ง แล้ว error ถูกกลืนเงียบ (C1)
- [ ] **BACKEND (PLC)** — แก้ข้อความแจ้งเตือน buffer เต็มที่นับจำนวนผิด (P5)

## วันที่ 4 — ความปลอดภัยที่เป็นบั๊ก (ไม่เปลี่ยนการใช้งาน)
- [ ] **BACKEND (LOGIN)** — ลบรหัสลับ JWT ค่าสำรองที่เขียนไว้ในโค้ด ให้ระบบแจ้งชัดถ้าไม่ได้ตั้งค่า และเพิ่มใน `.env.example` (S2)
- [ ] **BACKEND (EMAIL)** — ลบรหัสผ่าน SMTP ที่เขียนไว้ในโค้ด (S1) — *ผู้ใช้ต้องเปลี่ยนรหัสผ่านอีเมลจริงเองด้วย*

## วันที่ 5 — ข้อมูลข้ามบริษัท
- [ ] **BACKEND (บริษัท)** — แก้ให้แก้ไข/ลบการ์ด Dashboard, สร้าง Element ใน Interaction และตั้งค่า Level/Number ตรวจว่าเป็นข้อมูลของบริษัทตัวเองก่อน (S3)

## วันที่ 6 — หน้า Setting
- [ ] **หน้า SETTING (DEVICE)** — แก้กดเพิ่มอุปกรณ์แล้วฟอร์มอาจเปิดเป็นโหมดแก้ไข / ได้ข้อมูลผิด (Setting BUG-1, BUG-2, BUG-3)
- [ ] **หน้า SETTING** — แก้ error หลังปิดหน้า Setting แล้วระบบยังสั่งโหลดอุปกรณ์ และฟอร์มเปิดไม่ขึ้นแต่ไม่แจ้งอะไร (Setting BUG-4, BUG-5)

## วันที่ 7 — หน้า Dashboard
- [ ] **หน้า DASHBOARD** — แก้หน้าพังเมื่อยังไม่มีการ์ด และโหลดตัวกรองไม่สำเร็จแต่ไม่แจ้ง (DashboardLayout BUG-1, BUG-4)
- [ ] **หน้า DASHBOARD (การ์ด)** — แก้เลือกภาษาไทยแล้วการ์ดบางจุดยังแสดงอังกฤษ (DashboardCards BUG-3)
- [ ] **หน้า DASHBOARD (กราฟ)** — แก้ชนิดกราฟที่ไม่รู้จักแสดงพื้นที่ว่างโดยไม่แจ้ง และกดกรองซ้ำแล้วโหลดใหม่ทั้งที่ค่าไม่เปลี่ยน (Chart BUG-1, BUG-4)

## วันที่ 8 — หน้า Interaction / ส่วนอื่น
- [ ] **หน้า INTERACTION (ไฟสถานะ)** — แก้สีไฟเมื่อไม่ได้ตั้งค่าสี ให้ใช้สีเทาแทนแดง (StatusLamp BUG-2, BUG-4)
- [ ] **หน้า INTERACTION (เพิ่ม Element)** — แก้ปุ่มบันทึกกดได้ทั้งที่กรอกข้อมูลไม่ครบ (AddElementModal BUG-5)
- [ ] **หน้า SETTING (บทบาท)** — แก้ปิดหน้าต่างขณะกรอกข้อมูลค้างอยู่แล้วข้อมูลหายโดยไม่ถามยืนยัน (RoleSettingModal BUG-4)
- [ ] **หน้า DEMO** — แก้หน้าพังเมื่อตั้งค่าโหมด Auto (Demo BUG-1)

## วันที่ 9 — เวลา / เทสต์
- [ ] **BACKEND (เวลา)** — แก้เวลาของ Log/รายงานที่ลบ 7 ชม. แบบตายตัว และงานตั้งเวลาไม่ได้กำหนดโซนเวลา ทำให้เวลาเพี้ยนถ้าเซิร์ฟเวอร์ไม่ได้อยู่โซนไทย (C4)
- [ ] **เทสต์** — แก้เทสต์ `api.test.js` 3 ข้อที่ล้มเพราะ `localStorage.clear` ใช้ไม่ได้บน Node รุ่นใหม่
